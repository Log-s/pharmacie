# Interventions pharmaceutiques

Application web interne pour remplir des fiches structurées à partir de modèles (« templates »),
les exporter en PDF et consulter les documents de référence (« annexes ») qui s'y rattachent.

- **[Documentation technique](dev/index.md)**

    Vous installez, déployez ou faites évoluer l'application : architecture, conteneurs podman,
