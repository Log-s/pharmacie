# Annexes

Les annexes sont les documents PDF de référence (protocoles, procédures…) ajoutés par
l'administrateur. Tout le monde peut les consulter.

## Le menu Annexes

Le menu **Annexes** liste les documents avec leur titre et un extrait du contenu.

- **Rechercher une annexe** filtre par titre ou par contenu de l'extrait.
- Cliquez sur une annexe pour ouvrir le PDF dans un nouvel onglet.

## Depuis une fiche

Quand un champ renvoie à une annexe, son libellé est suivi d'une icône **i** :

- au survol, ou quand l'icône reçoit le focus clavier, une infobulle affiche l'extrait du document ;
- au clic, le PDF s'ouvre dans un nouvel onglet.

Sur une ancienne fiche, la mention **Annexe supprimée** signifie que le document a été retiré
depuis : demandez à l'administrateur la version à jour.

Pour ajouter, renommer ou supprimer des annexes, voir [Administration](administration.md#annexes).
