### Export PDF des annexes

`GET /api/annexes/export.pdf[?folder_id=<uuid>]` (les deux rôles) produit un PDF du sous-arbre du dossier choisi, ou de tout l'arbre sans `folder_id` (titre « Annexes »). Dossier inconnu : 404 « Dossier introuvable. ».

- Hiérarchie des titres : le nœud choisi est le `h1` ; un sous-dossier de profondeur d est un `h(min(d+1,6))` ; le titre d'une note est un cran sous son dossier ; les titres internes de la note sont décalés du même niveau (plafond `h6`).
- Tri alphabétique : sous-dossiers d'abord, puis notes. Les sous-arbres sans aucune note sont omis.
- Rendu dans `backend/app/pdf/annexes.py` (gabarit `annexes.html`, style `annexes.css`), avec le moteur et le chargeur hors ligne de `render.py`.
